# DeepSeek Harness 安装与更新

安装由 DSH 宿主插件管理器或 `dsh plugin --profile <实际名称> add <已验证制品>` 完成；当前兼容基线为 `0.2.2-rc.1`。不要把 Codex 插件缓存、marketplace 或 `server setup` 当作 DSH 的安装入口。

更新前按 `server status` 确认实际原生服务版本、实例与数据目录。保存服务数据备份；保留原 home、端口与 session ID。宿主替换本包并重载后，按新入口核对后台与 MCP 工具是否已实际切换；版本不兼容时不要自动覆盖或关闭共享的旧服务，按用户授权进行身份确认的停服和重启。

当前网页一键更新只处理 Codex 插件，不能用来更新 DSH 包。即使本机同时装有 Codex，DSH 的包版本仍需由 DSH 自己的安装器更新。安装、后台版本、技能发现、MCP 可调用是分别验收的结果。更新不代表评审通过，也不删除会话、B/R 快照、批注或归档。

npm 发布、社区目录收录、Discover 索引和 DeepSeek 账号登录互不等同。本包的本地 tgz 可用于隔离安装验证；只有公开发布和指定市场可发现性分别验收后，才可报告已经上架。
