## 工作简报

使用者是需要对照实际业务行为的策划、产品和开发者。任务是沿流程阅读条件与失败出口，留下带稳定对象位置的意见，并连续核对代理回应。界面应像逻辑审查工作台：内容清楚，外围安静，状态可靠。

领域概念：步骤、条件分支、失败出口、源码依据、批注落点、版本复核。颜色来自图与审阅标记：纸白画布、石墨正文、铅灰连线、蓝色选择和批注、琥珀色待复核、绿色确认。产品的识别点是流程对象与其旁批的直接关联，继续保留节点、路径和意见标记的联动。

## 观察与调整

改动前在隔离浏览器中检查了当时夹具流程的明暗主题、对象详情与手机页面，发现：外围按钮普遍带同等边框；导航同时包含编号框、选中框和箭头；详情类型与标题横向争用空间；回复再套卡片；多种蓝灰底色和外框共同增加了视觉碎片。

本轮做法：

- 保留蓝色识别，降低中性色的色度；选择、主要动作和业务状态继续使用有含义的颜色。
- 文件、评审信息与辅助工具减弱边框；浏览和框选使用一组分段控件，补充明确的语义分组。
- 场景编号采用无边框文字；选中态使用连续背景，步骤数保持辅助层级，长场景名继续自然换行。
- 桌面节点标题采用 15px/600，摘要 13px；手机标题保留 14px，并继续按实际画布缩放后的尺寸验收。
- 详情标题独立成行，正文采用 14px 和较宽行距；讨论回复用细分隔与留白组织，移除重复的回复卡片外框。
- 输入区域使用独立的填充和边框 token；浮层阴影使用中性颜色。手机仍保持 44px 触控目标和原有工具菜单。

没有增加字体下载、UI 组件依赖、装饰动画或新的业务入口；两种节点外观、独立讨论弹窗、单编辑器 DOM、IME、草稿、历史只读和异常备份继续保留。
