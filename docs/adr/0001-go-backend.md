# Go 后端与独立程序发行

在 `arch/go-backend` 独立实验分支中，将 LogicMargin 的 HTTP、MCP、CLI 与会话管理迁移到 Go，保留 React/TypeScript 前端，并将构建后的网页嵌入按平台发行的程序。目标是用户运行时无需安装 Node/Go，以及让服务端预计算、并发管理和本地工具发行使用同一套后端实现；前端构建阶段仍可使用 Node 工具链。

现有 TypeScript/Bun 原生包也能解决免装 Node，但本次选择同时验证 Go 后端的长期维护与计算方案。迁移先保持主要协议、存储、行为和前端功能，再单独加入结构 diff 预计算，以便分别衡量迁移与算法优化；尚未替换主线发行，兼容边界与具体测量见[验收记录](../go-backend-validation.md)。

迁移范围、兼容约束及验收方法见[迁移工作说明](../go-backend-migration.md)。

后续规划包括多用户同时审查。用户于 2026-11-09 明确要求本次只记录规划，迁移完成后独立评估；本轮保持会话隔离、并发冲突检查与事务边界，不增加账号、权限或多人协作协议。
