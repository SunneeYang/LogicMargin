# LogicMargin 布局重设计：先把屏幕交给流程图

状态：用户已确认以 B 为默认：展开左侧场景列表，压缩顶部并使用全高画布；折叠导航与专注模式作为可选状态。正式工作台已按此落地，保留既有批注、草稿、回复、提交、复核及系统主题。

## 旧版量测到的问题

使用真实魔灵秘境评审包，在 Chrome 中按初始视角量测，页面未向下滚动。以下“可见高度”指画布与屏幕实际交集，不等于 CSS 设置的面板高度。

| 屏幕 | 当前画布起点 | 画布自身高度 | 首屏实际可见高度 |
| --- | ---: | ---: | ---: |
| 1366×768，关闭成功提示 | 约 452px | 420px | 约 316px |
| 1440×900，关闭成功提示 | 约 452px | 420px | 420px |
| 1920×1080，关闭成功提示 | 约 452px | 约 585px | 约 585px |
| 1366×768，导入成功提示显示中 | 约 513px | 420px | 约 255px |
| 375×812，导入成功提示显示中 | 约 772px | 440px | 约 40px |

当前文档区约 245px、场景说明约 87px、工具栏约 52px，再加顶栏 68px。导入成功提示还会额外增加约 61px。`.canvas` 的保底高度不保证其全部留在屏幕内，主栏滚动和图内平移又成为两套操作。

右栏打开时，桌面固定左侧 216px、右侧 352px。横向剩余空间变少，但画布上方文字仍占大量高度。图默认靠左起笔，纵向主线也没有因屏幕变宽而受益。

## 已确认 B：展开场景列表与全高纵向画布

采用 48px 全局栏、44px 画布工具带；其余高度交给画布。若保留 24px 底部状态带，1366×768 的画布目标为约 652px，1440×900 为约 784px。这里是正式布局目标，不包含原型比较切换条，也不是效率提升承诺。

- 全局栏：评审名称、保存状态、文件菜单、提交本轮。完整版本、源码来源和覆盖范围按需展开。
- 工具带：当前场景名、浏览/框选、定位当前对象、查看讨论、专注画布。低频导入样例、整场景/整个评审批注收进对应菜单。
- 左侧：桌面默认展开约 192px 场景目录，直接看见各场景与当前位置，长标题可换行。需要更宽的图时可显式收起，专注模式临时隐藏导航；当前场景始终在工具带可见。
- 右侧：选中后按需打开约 320px 的详情/讨论；桌面在布局中分配独立区域，尽量保持目标可见。长回复在侧栏内滚动。空间不足时收起导航或转为可关闭的底部面板。
- 成功反馈浮动显示，保存状态就地更新；它们不改变画布尺寸。需要操作的保存/恢复错误保留明确入口，不靠短暂提示承载。
- 整个工作台占满可视区域。图内平移/缩放，侧栏独立滚动；阅读图时不再需要先滚页面找画布。
- 专注模式隐藏次要导航和面板，只保留退出、当前场景和必要画布操作；Esc 先遵守编辑器关闭规则，再退出专注，不丢草稿。

## 流程图本身怎样利用空间

默认保留由上到下的业务顺序，把主线和失败分支组合居中放在可用画布中，避免从宽画布左上角开始留下大块无用空白。

节点默认展示类型、业务标题和短摘要；长规则、输入输出、源码与讨论放入右栏。保持可读字号，长标题允许自然折行，不为了同时塞下全部节点不断缩小。

横向布局仅在比较原型中试验，本轮正式实现保留纵向。若后续增加显式横向选项：主线从左到右，失败分支放在下方；重排只改变视图坐标，目标 ID、批注、草稿与原始关系不变。不能直接交换 x/y：当前节点宽 248px、纵向步距 180px，横向需要约 310–330px 步距。也不随窗口 resize 自动改变方向，避免用户失去阅读位置。

“全图概览”用于找位置，“定位当前步骤”用于可读阅读。12 步的战斗流程仍允许连续平移，不以缩小整张图作为默认答案。本轮在折叠导航、打开详情和切换专注状态时保持缩放与阅读位置；显式切换场景仍从该场景入口开始。

## 用同一真实数据比较三个布局

[交互布局原型](../public/layout-prototype.html)提供三个方案，通过底部切换条或 `?variant=A/B/C` 比较。

| 方案 | 结构 | 取舍 |
| --- | --- | --- |
| A，可选专注方向 | 压缩双行工具区、折叠工具轨、全高画布、按需右栏 | 给画布最多空间，需把场景菜单做得易发现 |
| B，已确认默认 | 单行全局栏、固定场景导航、全高纵向图、按需右栏 | 场景更好找，但固定消耗约 176–192px 宽度 |
| C，局部复核参考 | 横向分段主线、可收起的底部详情、前后段导航 | 适合逐条复核，需明确隐藏的跨段关系；不建议作为默认全图阅读 |

三种方案都使用魔灵秘境的真实场景、节点和连线。原型不连接真实批注存储，不代表正式应用已支持所有新布局操作，也不会修改已有意见。

原型检查：A/B/C 在 320、375、414、768、1366、1440、1920px 宽度均无页面横溢或脚本异常；已检查场景切换、12 步战斗流程、按需详情、方向切换、专注/退出、分段下栏收起及手机底部详情。原型自身比较条和方案说明占用额外约 132px，不能把原型画布尺寸直接当作正式布局目标；例如 A 在 1366×768 原型中的画布为约 1312×542px，移除比较区后正式版仍按上文的全高目标落地。
