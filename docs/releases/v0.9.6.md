# LogicMargin 0.9.6

Adds configurable keyboard shortcuts for common review actions and a centered Settings dialog. Interface, keyboard shortcuts, and version updates have separate tabs. Bindings can be recorded, disabled, or reset, with conflict checks and browser-reserved keys protected. Preferences survive reloads without entering review data.

Shortcuts reuse existing scene, canvas, discussion, details, code layout, and difference-navigation operations. Typing and IME composition do not trigger global actions. Code actions target a single visible comparison and preserve its editor for navigation and context expansion. The review shortcut opens the existing confirmation flow; it never submits or approves directly.

Includes the Codex marketplace source-switch recovery fix prepared under the preserved v0.9.5 tag. That release workflow was canceled before publication to include these requested features. The updater snapshots the previous marketplace, switches to the pinned official release, and restores registration on removal/registration failures or cancellation. Existing published tags are unchanged.

---

- 设置改为居中独立窗口，分为“界面、快捷键、版本与更新”，沿用已有主题、语言与代码布局偏好。
- 常用操作提供 24 项可修改绑定，支持录制、冲突提示、停用、单项恢复与全部恢复。键位按浏览器站点保存，输入文字或使用输入法时不误触全局操作。
- 代码快捷键作用于当前聚焦或可见的一个对照；差异导航与全文展开保留编辑器，布局仍支持统一和并排。审查快捷键只进入原有确认流程，不直接提交或通过。
- 包含 Codex 同名 marketplace 切换 Git ref 的备份与恢复修复。v0.9.5 的发行在公开前取消，标签保留；本版重新运行三系统门禁并提供五平台原生 ZIP 与 SHA-256。

真实更新测试使用带修正版更新器、标为 0.9.2 的源码预览作为起点；未修改的官方旧版本不具备该更新器。旧更新器遇到来源冲突时需先按安装说明完成一次 Agent 更新。更新可能短暂中断服务，MCP 宿主可能需要重连；跨平台 CI 与本机完整升级分别验收。
