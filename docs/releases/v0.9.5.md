# LogicMargin 0.9.5

Unpublished: the release workflow was canceled before publication to include configurable keyboard shortcuts and the new Settings dialog in 0.9.6. The tag is retained.

Fixes one-click Codex plugin updates when the configured marketplace uses a different Git ref. Codex refuses to overwrite that source directly. The updater now snapshots the previous marketplace, removes only its registration, adds the pinned official release, then separately refreshes and installs the plugin. Registration failures and cancellation after removal restore the previous snapshot with a bounded recovery context; the old service and review data remain recoverable.

0.9.5 retains the structural diff, full-source analysis context, saved code-layout preferences and five native platform packages introduced in 0.9.4. Structural analysis remains a syntax aid with conservative text fallback.

---

修复 Codex 同名 marketplace 使用不同 Git ref 时，一键更新被拒绝的问题。

- 更新前保存原 marketplace 目录快照，仅移除该来源注册，再注册固定官方版本、刷新并安装；其他 marketplace 不受影响。
- 移除已生效后取消，或新版本注册失败时，使用独立有界恢复过程重新注册旧目录快照并恢复旧服务。移除来源不会删除插件缓存，但重新注册前插件暂时不在清单中。
- 拒绝备份来源包含备份目标的路径，避免本地 marketplace 自递归复制；保留单写者、官方 SHA-256、版本核验和评审数据备份。
- Codex 子命令失败会标明具体步骤。目录恢复失败会明确报告 `codex_marketplace_restore_failed` 并保留快照供诊断。

0.9.4 的真实升级测试确认了这一问题，旧服务已安全恢复；0.9.5 增加对应的成功、注册失败、移除后取消、移除提交后报错及备份路径回归。已有旧版更新器遇到来源冲突时，需由 Agent 按安装文档完成一次更新；随后使用新版网页更新器。升级后 MCP 可能需要宿主重连。

本版沿用 macOS arm64/x64、Linux arm64/x64、Windows x64 五个原生 ZIP、逐包 SHA-256 与 `SHA256SUMS`。完整三系统门禁重新执行；真实机器的完整插件升级演练与 CI 内的隔离命令/进程测试分别报告。
