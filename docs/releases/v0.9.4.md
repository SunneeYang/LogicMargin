# LogicMargin 0.9.4

Version 0.9.4 improves node code review and adds verified local updates for an existing Codex installation.

- Side-by-side code is the default; layout preferences survive node/scenario changes and reloads. Valid structural focus is applied automatically while complete text diffs remain available.
- The backend can analyze version-verified full source files, share parsing across nodes, and project results back into saved snippets. Full analysis sources are not included in review JSON or browser responses.
- Settings shows the running service version and checks official releases. A loopback page can update the local plugin and service with pinned assets, SHA-256 checks, backup, restart, and actual-version verification; remote pages can check only.
- Five native platform ZIPs and checksums remain available. Structural analysis is a syntax aid, with conservative text fallback for unsupported or over-budget inputs.

## 评审阅读

- 代码对照默认并排；统一/并排布局可在代码页或设置中修改，跨节点、场景和刷新保留。
- 结构结果就绪后自动采用结构重点；不再要求手动切换文本/结构模式。未支持的语法或分析失败时保留完整文本差异并说明原因。
- 优先展示有变更的节点源码；新增或取消关联的片段显示增减对照，并明确其关联范围。
- 停靠的节点阅读器切场景后保留当前页签，随后跟随新节点。结构结果更新时保留上下文展开、滚动、选择和总览焦点。
- 总览按连续变化行合并结构 token 标记，避免大段删除创建数千个重复 DOM 标记；离屏代码继续按需渲染。

## 完整源码结构分析

- Go CLI 在来源核验时捕获版本绑定的完整文件，发布后仅上传到本机的可选分析缓存；全文不进入评审 JSON 或浏览器响应。
- 后端复用全文解析与匹配，再把结构重点映射回节点的原始保存片段；固定 B 与历史源码不会被当前工作区内容替换。
- 结构计算使用独立的有界 worker 队列并扩充解析预算；普通 diff 与流程图保留原计算路径。输入与缓存预算仍共享。
- 修复 JS/TS 字符串包含转义时被误判为语法无效的问题。语法不支持、上下文缺失或预算耗尽仍可回退文本。

## 版本与本机更新

- “外观”菜单改为“设置”，分组管理界面偏好与版本更新。
- 显示真实运行服务版本，手动检查官方稳定版；GitHub API 限流时使用同仓库的官方发行页核验回退。
- 本机回环页面可一键更新已有 Codex 插件与服务：固定官方版本、SHA-256 校验、备份、重启及真实版本核对；保留原端口、数据目录、评审和批注。
- Tailscale/局域网页面可检查新版，安装须在服务本机操作。更新后 MCP 可能需要宿主重连。

## 跨平台修正

- macOS 缓存测试先解析系统临时路径的真实目录，保留运行时拒绝符号链接的检查；Windows 不把 Unix 权限位断言当作 ACL 验证。
- Node 兼容后端在 Windows 删除竞态中遇到 `EPERM` 时，再次确认活动文件是否已不存在；已删除/归档仍返回 404/410，真实权限问题继续保留错误。
- 0.9.3 候选标签在发行门禁发现上述问题，未公开 Release；保留该标签，以 0.9.4 重新执行完整门禁。

## 分发与验证

提供 macOS arm64/x64、Linux arm64/x64、Windows x64 五个原生 ZIP、逐包 SHA-256 与 `SHA256SUMS`，运行无需 Node.js 或 Go。

发行流程以三系统原生测试和五目标构建为门禁。本机已验证相关 Go race、前端类型/单元测试与 Chrome 回归；跨架构实体设备、真实手机及服务 CPU/峰值内存不在本机验收范围。首次大型 JS/TS 全文解析仍有实际计算成本，结构结果只作语法阅读辅助，不证明通用语义等价。
