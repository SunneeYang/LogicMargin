# LogicMargin 0.9.17

Review reading now has one continuous path: select **Start review** beside the canvas review panel, then use **Previous / Next** in the reading window. Entry starts at the oldest unresolved comment, switches scenes and locates its target automatically. The default shortcuts are `Shift+R`, `[` and `]`, and can be changed in Settings. Navigation preserves code layout and reply drafts; it does not submit feedback or approve a review.

Node windows combine details and discussion into one tab, with the details above the complete chronological discussion. Source evidence stays in the code diff tab. Current-round reviewer text and replies can be edited before submission; fixed submissions, older rounds and agent replies remain read-only. Concurrent edits are rejected without overwriting local text, and a lost save response can be replayed safely.

Opening a discussion from its canvas marker preserves the current view. Entering or restoring a draft reveals the complete form after discussion positioning, while new phone comments keep the keyboard closed until selected. Mobile node visibility also accounts for the floating selection toolbar so it does not block the discussion button.

Fixes a canvas failure when Escape closes a discussion while a node retains keyboard focus. Discussion handlers stay current without rebuilding the node list during selection changes.

Resolved comments stay resolved across unrelated changes. A substantive change to their associated logic or captured code, or a new agent reply, requests human review again. Global revision/fingerprint changes and line-number movement alone no longer reopen a previously confirmed comment.

Layout improves main-path alignment, joins, side branches and orthogonal port ordering. Independent before/after diagrams retain independent placement when they share no nodes. These are general layout rules; the review's nodes and connections are not rewritten, and arbitrary graphs are not guaranteed to have no crossings.

This release includes five native platform ZIPs, the DSH bundle and SHA-256 checksums. DSH compatibility remains pinned to `0.2.2-rc.1`. Existing review IDs, submissions, history and source snapshots are preserved.

- 节点窗口合并详情与讨论；代码依据保留在代码 diff 页。讨论及回复按时间正序，本轮未提交的人工正文可原地编辑；固定提交、历史内容和代理回复保持只读。
- 已确认解决的意见不再因全局版本、源码指纹或行号变化统一重开；仅关联逻辑/代码实质变化，或有新代理回复时，重新要求人工复核。
- 优化主线、合流、旁支及正交端口布局；前后版本无共同节点时分别布局，不修改业务连接关系。
- 保留代码布局、回复草稿和原评审数据；导航不代替提交、确认解决或批准。五平台原生包及 DSH 包统一为 0.9.17。
