# LogicMargin 0.9.16

Fixes an intermittent development and preview proxy failure where an untrusted-Origin write received HTTP 502 instead of the Go service's HTTP 403. The proxy now uses Node's standard HTTP Agent instead of forcing the upstream connection to close during an unfinished upload. The original Host, Origin validation and local-only MCP boundary remain in place; write requests are not retried.

Real dev and preview regression tests check the exact rejection status and body across repeated uploads. The integration also checks an MCP wait lasting beyond five seconds. Go request limits, parsing/computation budgets, review storage and runtime APIs are unchanged. The Go-only development and test entry points introduced in 0.9.15 remain the default.

Structure analysis now distinguishes its own deadline from caller cancellation. Internal deadlines return a source-bound text/budget fallback; temporary wait results leave shared computations and caches intact, while existing computed budget artifacts remain reusable. Caller cancellation, shutdown errors and the original 12-second analysis and 15-second worker budgets are preserved.

The shared Codex and DSH skill now confirms the actual review access network before creating or opening a review. It checks the native service separately from a real read-only MCP call, and falls back to the CLI when a healthy compatible service is available but the host cannot restore MCP. `wait --no-consume` preserves feedback and approval cleanup for explicit acknowledgement and archival; the legacy CLI default remains compatible. Fixed-release download failures and older CLIs without this flag are reported separately.

The 0.9.15 Release and its history are preserved. This Release ships matching five-platform native ZIPs, the DSH tgz, six SHA-256 sidecars and `SHA256SUMS`. DSH compatibility remains pinned to `0.2.2-rc.1`; GitHub distribution does not publish npm or alter marketplace listings. Existing installations, services, profiles and review data are not changed automatically.

---

- 修复源码开发和预览代理偶发把 Go 的跨域拒绝 403 转成 502：使用 Node 标准 HTTP Agent，避免上传未结束时强制关闭上游连接。
- 保留原始 Host、Go 的 Origin 校验与 MCP 本机边界；不自动重试写请求，不放宽上传限制或计算预算。
- 真实 dev/preview 回归重复核对拒绝状态和正文，并覆盖超过五秒的 MCP 等待。Go 保存格式与运行时 API 不变，继续使用 0.9.15 引入的 Go 开发测试入口。
- 保留已公开的 0.9.15 标签、附件和失败记录；同版重建五平台 ZIP、DSH tgz 及摘要。DSH 兼容基线仍为 `0.2.2-rc.1`，不自动发布 npm、修改市场、本机安装或评审数据。

- 结构分析区分内部期限和调用方取消：内部超时返回保留片段摘要的 text/budget；临时等待回退不覆盖共享计算或缓存，已有预算结果仍可复用。外部取消、服务关闭和原有 12 秒分析/15 秒任务预算保持不变。

- Codex/DSH 技能在新建或打开评审前按实际设备与网络确认范围，分别检查后台健康和真实 MCP 只读调用。健康后台上的握手失败可安全回退原生 CLI；新增 `wait --no-consume`，读完反馈后才显式领取/归档，旧默认 CLI 行为保持兼容。固定版附件缺失和旧 CLI 不支持该开关会明确说明。
