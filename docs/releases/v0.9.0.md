# LogicMargin 0.9.0

> This tag remains a historical candidate and has no published release assets. Use [v0.9.2](v0.9.2.md), which also fixes the retained Node compatibility backend's Windows cache invalidation. 此标签保留为历史候选，未发布附件；请使用 [v0.9.2](v0.9.2.md)。

LogicMargin now ships as a native Go program with the review UI embedded. Users no longer need Node.js, Bun, Go, or npm to run the released plugin.

- Review sessions, fixed B/R snapshots, discussions, CLI and HTTP MCP retain the existing data format.
- Text diff and flowchart geometry are precomputed and cached on the backend. Text remains available while structural analysis runs separately.
- **Structural focus** reduces formatting noise and adds a local comparison for clearly identified moved or moved-and-modified functions. It preserves strings, comments and actual token changes. Unsupported, invalid or over-budget inputs retain the complete text diff.
- The Git marketplace uses version-pinned native launchers with SHA-256 verification; platform ZIPs include the native executable directly.
- README screenshots and installation instructions are updated in Chinese and English.

## Upgrading from 0.8.x

Keep the actual session directory and your existing backups. Stop the old owned service before starting the new program against the same directory. Reconnect/reload the host MCP connection after updating; a successful download alone does not reload the tools. The underlying session format is retained. Never run Node and Go as simultaneous writers of one session directory.

Structural analysis is syntax-aware assistance, not a general proof of semantic equivalence. Large/dense TS inputs can reach the analysis budget and stay in text mode. Multiuser accounts, permissions and collaboration protocols are not part of this release. Build and test scope is recorded in the migration and structural-diff documentation.

- 中英文说明和配图已更新。

升级时保留实际会话目录与备份，先停止旧的受控服务，再用新版读取同一目录；更新后重连或重载宿主 MCP。下载成功不等于工具已经重载。不要让 Node 和 Go 同时写入同一会话目录。

结构分析是语法阅读辅助，不是通用语义等价证明；大段或密集 TS 可能达到预算并使用文本模式。本版尚未提供多人账号、权限和协作协议。构建与实测范围见迁移和结构差异说明。
