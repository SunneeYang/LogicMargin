# LogicMargin 0.9.15

The legacy Node backend and CLI have been removed. Development, preview, browser tests, native package lifecycle checks and command-line review now use the same Go service and CLI shipped to users. `npm run dev` pairs Vite hot reload with the Go backend; `npm run review -- ARGS` builds and invokes the current Go source. `npm test` runs Go backend tests and frontend unit tests, and `npm run test:e2e` uses Go by default.

Frozen historical session, HTTP, source-verification and MCP expectations remain independent compatibility fixtures. Native multi-process startup, crash recovery and isolated host integration remain covered. Existing review data and the saved session format are unchanged. Development and preview proxies preserve the local-only MCP boundary using the original socket peer.

JavaScript and TypeScript remain for the React frontend, the DSH host bridge, build/test orchestration and embedded parser/layout bundles. End users still need no Node.js or Go runtime for the native LogicMargin service. Source development now requires Go as well as Node.js; obsolete Node/Bun backend packaging and profiling entry points are no longer available.

The Release includes five native platform ZIPs and the matching DSH tgz, their SHA-256 sidecars and `SHA256SUMS`. DSH compatibility remains pinned to `0.2.2-rc.1`; its package updates use the DSH host installer. GitHub Release publication does not publish npm or change community/Discover listings. This release does not update local installations or alter running services automatically.

---

- 删除旧 Node 后端、CLI 及对应的过时打包和性能分析入口，源码开发、预览、命令行和浏览器测试统一使用 Go 服务。
- `npm run dev` 使用 Vite 热更新和 Go 后端；`npm run review -- 参数` 构建并调用当前 Go CLI；`npm test` 运行 Go 后端与前端单测，`npm run test:e2e` 默认使用 Go。
- 保留冻结的历史会话、HTTP、源码核验与 MCP 契约，以及原生多进程启动、崩溃恢复和隔离宿主验收。保存格式不变，不迁移或删除现有评审数据。
- 开发与预览代理按原始 socket 来源限制 MCP，维持本机工具调用边界。
- 前端、DSH 桥接、构建测试编排和内嵌算法仍保留必要的 JavaScript/TypeScript。原生服务的使用者仍无需 Node.js 或 Go；源码开发需要同时安装两者。
- 同版发布五平台 ZIP、DSH tgz 和摘要；DSH 兼容基线仍为 `0.2.2-rc.1`。GitHub 分发不等于 npm 发布或市场收录，也不会自动修改本机安装、服务及评审数据。
