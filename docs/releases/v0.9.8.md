# LogicMargin 0.9.8

Adds a DeepSeek Harness plugin and improves orthogonal diagram layout. The DSH bundle registers the shared review skill, starts or reuses the native service, and connects all 11 review tools through the official MCP Client. Compatibility is pinned to DSH 0.2.2-rc.1. Its long tool timeout supports human review; cancellation and plugin unload do not acknowledge feedback or archive sessions. Reloading after a service restart resumes the saved session, not an old in-flight call.

Comparison diagrams preserve each side's authored topology when shared nodes admit an exact rigid alignment. B/R switching keeps shared positions stable. Dagre fallback routes remain orthogonal, including after DOM rounding and node hover or selection. Cross-stage exits use side ports to keep adjacent main stages straight, while simple corner candidates remove unnecessary zigzags without bypassing node or label avoidance. Reduced crossings can require longer outer tracks; this is not a global crossing-free layout guarantee.

Download the DSH bundle and its SHA-256 from this Release, verify the checksum, then install it into the intended profile:

```sh
dsh plugin --profile YOUR_PROFILE add /absolute/path/dsh-plugin-logicmargin-0.9.8.tgz
```

The bundle downloads the matching native ZIP on first activation. DSH package updates are managed by DSH; the web page's one-click updater currently targets Codex only. GitHub Release distribution does not imply npm publication or Discover/community listing. The project and generated packages now include the MIT license.

The v0.9.7 tag is preserved without a public Release: its gate found that a large-file syntax test incorrectly required success within a hardware-dependent five-second deadline. This release gives syntax correctness its existing test-owned deadline while retaining the production five-second timeout, input limits, cancellation and text fallback. It does not claim faster parsing or remove large-file fallback.

- 新增 DeepSeek Harness 适配，兼容基线为 `0.2.2-rc.1`：自动启动或复用 Go 后台、加载评审技能及全部 11 个 MCP 工具，沿用固定 B/R、批注、领取和多轮复核协议。
- 长等待不因保存批注而提前结束；取消、断线和卸载不自动领取或归档。服务重启后须重载插件，再核对原会话继续，旧在途调用不会自动续接。
- 改善 B/R 比较图的拓扑合并，保留可以整体对齐的原布局；修复自动布局、DOM 取整与节点浮起时的斜线。主线与跨步出口分离，减少交叉和无意义转折，仍保留节点与标签避让。
- 本 Release 提供五个平台的原生 ZIP、DSH tgz、各自的 SHA-256 及统一 `SHA256SUMS`。DSH 从本 Release 直接安装；npm 发布、社区目录与 Discover 收录各自独立，不能据此声称已上架市场。
- 项目及发行包采用 MIT。现有会话格式保持兼容；升级仍须确认旧后台身份、备份数据并保证单个写入者。跨平台 CI 与本机 DSH 集成分别验收，不把交叉构建等同于目标系统运行。

DSH 的隔离 Web Host/MCP/技能验证不等于 Desktop 或模型执行验收。网页一键更新目前只更新 Codex 插件；DSH 包和后台版本需分别核对，不能通过 Codex 更新器代替 DSH 宿主安装。

`v0.9.7` 因门禁发现大文件正确性检查依赖机器速度，未公开 Release，标签保留。本版拆开内容正确性与生产超时验收：保留生产 5 秒、全文总预算 12 秒、输入上限、取消与文本回退，不承诺大文件不再触发预算。
