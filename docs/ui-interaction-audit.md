# 评审界面交互审查与精简

2026-11-03。基于当前 React 网页、交互源码、隔离浏览器检查和自动回归；采用 Hallmark 的层级、克制、状态反馈与可访问性检查，并结合渐进披露和重复入口合并。保留现有 Cobalt 工具界面、系统明暗主题、品牌及数据契约。本次是启发式审查，没有用户访谈、任务完成率或 A/B 测试数据。

## 主操作心流

1. **看图**：选择左侧场景，在画布平移、缩放和选择对象；评审目的与覆盖范围按需打开顶部“评审信息”。
2. **留下意见**：节点批注按钮直接写意见或打开完整讨论；连线和多选保留“批注所选”，范围意见从“添加批注”进入。
3. **核对与复核**：统一从“评审面板”进入讨论、当前对象详情、已有草稿和本轮变化；节点上的讨论仍在独立弹窗内阅读及处理。查看修改前/当前版本不会改变意见落点。
4. **提交或完成**：顶部唯一入口根据当前状态进入提交、定位待处理意见或确认完成。整轮通过须在确认区完成；草稿不阻塞通过，也不会被清空。
5. **管理记录**：文件菜单承载导入、导出、完整备份、评审任务及全部本地历史归档；任务按审查目的隔离，低频和危险动作放在各任务的“更多操作”。

## 主要问题与处理

| 优先级 | 问题 | 本次处理 |
| --- | --- | --- |

| 高 | 工具栏三个面板入口与右侧标签重复 | 合并为一个“评审面板”，首次打开讨论，之后记住最后标签。 |
| 高 | 详情页再次铺开全场景节点、连线按钮与覆盖范围 | 移除重复目录和范围；画布仍提供鼠标、键盘和触控选择，范围集中在评审信息。 |
| 高 | 详情页又完整渲染相关意见，与独立讨论弹窗重复 | 改为“查看相关讨论”入口，打开当前所选对象全部相关意见、回复与处理动作。 |
| 高 | 侧栏直接批准与顶部确认批准有不同语义 | 删除侧栏批准入口，只在顶部确认区完成；已通过以静态状态显示。 |

| 中 | 普通步骤细节夹杂输入输出、零源码提示和哈希 | 规则正文只补充图中未展示的内容；输入输出和非空源码按需展开，不常驻 SHA。 |
| 中 | 浮动草稿入口与图例、显示方式占据同一角落 | 移除浮动草稿入口；原目标批注入口和面板草稿恢复保留。 |
| 中 | 选中单节点又出现一枚批注按钮 | 节点保留自己的按钮；浮动批注只在多选或选中连线时出现。 |
| 中 | 顶部导出、任务管理和历史返回重复 | 导出和任务集中到文件菜单；历史返回统一用版本切换；R1只显示静态轮次。 |
| 中 | 编辑器“稍后继续”与关闭动作相同 | 保留头部关闭、自动保留提示及唯一保存主动作。 |

| 低 | 左侧、画布底部和选中浮层反复解释操作 | 移除左侧教学和选中后的前后关系教学条；完整操作说明集中到图例。 |

## 可交互组件清单

| 区域 | 保留的交互 | 条件与边界 |
| --- | --- | --- |
| 顶栏 | 导航开关、评审信息、文件菜单、提交/复核/完成 | 已通过使用状态；历史视角没有提交动作；保存或同步错误保留明确恢复入口。 |
| 评审信息 | 范围与“技术信息”展开 | 目的、范围、版本优先；仓库、提交、指纹、采集时间和会话标识折叠。 |
| 文件 | 导入、导出、样例、返回本机、评审任务、完整会话备份、归档全部本地历史 | 会话中隐藏不可用的本地导入/样例；全部本地历史归档不再混在某个评审的讨论底部。 |
| 场景导航 | 场景按钮、窄屏场景选择、开关与遮罩 | 桌面与窄屏是响应式替代；各场景视角与缩放保持现有规则。 |
| 画布工具 | 浏览/框选、评审面板、添加范围批注、选中定位、专注画布 | 无选择不显示定位；专注可用 Escape 返回；框选只选节点。 |
| 画布对象 | 点击/键盘选择、Shift/⌘/Ctrl 多选、节点批注、节点/连线右键、连线双击 | 批注以稳定对象 ID 定位；历史只读时只读取已有讨论。 |
| 画布选区 | 多选/连线的批注所选、清除选择、多目标意见索引 | 不再给单节点重复批注入口；跨对象意见仍可直接打开。 |
| 阅读控件 | 放大、缩小、完整流程、手机恢复阅读视图、简洁/多样式、图例 | 手机默认保持可读字号，整图总览可一键返回阅读；显示方式与图例折叠，偏好记忆保留；选中路径流光与减少动态效果设置保留。 |
| 多轮版本 | 修改前、当前、本轮变化、旧意见原位置 | 当前版本重复点击不清空选择；R1无伪切换按钮；旧轮保持只读。 |
| 评审面板 | 讨论、详情、已有草稿、变化、关闭 | 草稿为零不常驻空标签；切换标签仍能看到对应正文，不删除正在编辑的内容。 |
| 对象详情 | 输入输出展开、源码展开、多选逐项移除、相关讨论 | 不再重复整图目录、范围或完整线程；无源码时不显示空折叠。 |
| 讨论 | 按状态筛选、逐条复核/退出、当前/原位置、回复、确认解决、仍需处理、重新打开 | 保留全部原意见和回复；连续复核保留“并下一条”；未发布新版禁止替人确认修改完成。 |
| 固定记录 | 展开、逐份下载 | 仅在有记录时显示；完整固定快照与轮次保存不变。 |
| 草稿 | 继续编辑、更多中的单份导出/导出并移除、多份导出 | 仍按版本和目标保留；旧版本不能自动重挂到新对象，仍可导出核对。 |
| 批注编辑器 | 输入、保存、快捷键、头部关闭、浮窗/侧栏互转 | IME 组合输入保护、原目标、选区、DOM 与草稿保留；关闭不等于提交给代理。 |
| 节点讨论弹窗 | 所有关联历史与回复、线程处理、回复输入、关闭 | 保留独立弹窗与移动端 sheet；不改回侧栏；焦点返回原节点标记。 |
| 提交确认区 | 已保存意见提交、包含草稿提交、整轮确认、取消 | 包含草稿与不包含草稿产生不同结果，不能作为冗余合并删除。 |
| 任务管理 | 新建展开、目的/关联会话/清理策略、刷新、打开/恢复、更多操作、删除确认 | 目的隔离、备份、归档和恢复保留；永久删除仍须明确确认，未完成任务不开放隐式清理。 |
| 恢复与异常 | 重连、未同步意见备份、备份后恢复服务端、损坏数据分项备份、正确类型的导出 | 正常加载不提供无意义重连；错误、草稿与历史分别保护，不以精简为由移除。 |

## 验证边界

重点回归：侧栏切换时保留编辑器 DOM/输入/锚点；详情只通过独立弹窗读取完整讨论；顶栏唯一完成及草稿不阻塞契约；历史只读、移除目标、未发布保护；四种窄屏尺寸与明暗主题；错误备份与任务生命周期。

审查与测试均使用隔离数据。真实会话仅做更新前备份及更新后完整性核验，不添加、回复、解决或批准真实意见。功能自动回归不能代替真人可用性验证。

手机反馈暴露了原检查的不足：只断言无溢出和控件入屏，未检查缩放后的实际字号和触控面积。新增真实移动 Chrome 上下文（`isMobile`、`hasTouch`、DPR 2.2/3），覆盖 390×844 与 684×584 短宽视口；测量画布变换后的文字和按钮尺寸，验收单排工具栏、总览返回阅读、明暗主题、触控草稿恢复/批注回复及 R2 历史切换和旋转。仍未模拟实体软键盘或移动 Safari。

2026-11-04 追加：展开工具菜单时，“专注画布”错误沿用了 44px 图标按钮宽度，文字和图标各越界 14px。手机菜单改为完整宽度的左对齐操作行；新增 320 / 390 / 684px 触控检查，用实际文本 Range 和 SVG 边界验证每个工具控件，覆盖明暗主题、侧栏开关、选中及专注进入/退出。

验证结果：严格 TypeScript 检查、生产构建与 93 项 Chrome E2E 通过，覆盖 320 / 375 / 414 / 768px 与真实移动上下文的 390×844 / 684×584、系统明暗主题、长讨论和回复输入框的完整可见性。手机标题实际字号恢复为 14px，批注按钮保持至少 44px 高，工具栏为 54px，缩放控件横排。尚未进行真人触控设备或 Safari / Firefox 验收。
